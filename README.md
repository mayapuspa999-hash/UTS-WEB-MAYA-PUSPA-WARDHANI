## Fitur

| Fitur | Penjelasan |
|---|---|
| Kalkulator Estimasi Biaya Proyek | Menghitung biaya dari jenis website, jumlah halaman, dan fitur tambahan. Diskon 10% jika subtotal di atas Rp 500.000. Hasil langsung tampil di halaman, lengkap dengan validasi input. |
| Dark Mode Toggle | Beralih tema terang/gelap, pilihan tersimpan di browser. |
| Filter & Search Proyek | Menyaring kartu proyek berdasarkan kategori (HTML, CSS, Bootstrap, JavaScript) dan kata kunci. |
| Validasi Form Kontak | Nama, email, dan pesan dicek sebelum dikirim, dengan pesan error per kolom dan penghitung karakter. |
| Dashboard ringkas | Kartu statistik yang ikut berubah (jumlah proyek tampil, estimasi terakhir). |
| Lainnya | Navbar scrollspy, tombol kembali ke atas, animasi scroll (AOS). |

## Teknologi

HTML5 semantik, Bootstrap 5.3.8, Bootstrap Icons, AOS, CSS kustom
(`css/style.css`), dan JavaScript (`js/script.js`).
